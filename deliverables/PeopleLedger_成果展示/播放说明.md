# PeopleLedger 成果展示 / Project showcase

20 页中英文页面，中文语音讲解。自动演示时长约 **18 分 50 秒**，包括每页语音结束后的 1.5 秒间隔。

## 在 PowerPoint 中播放

1. 打开 `PeopleLedger_自动播放_中文配音.ppsx`，以幻灯片放映模式观看。
2. 如需编辑，打开 `PeopleLedger_中英成果展示_中文配音.pptx`；按 **F5** 从第一页开始放映。
3. 保持“使用计时”和“播放旁白”开启。语音已经嵌入文件，无需另行下载音频，也无需联网播放。
4. 按 **Esc** 退出放映。逐页中文讲稿同时保存在演讲者备注和 `PeopleLedger_中文讲解稿.md` 中。

推荐使用桌面版 Microsoft PowerPoint。本次已在 Windows PowerPoint 验证文件可以打开，并检查每页媒体及自动换页设置；其他演示软件的音频行为可能不同。

## 在线展示页

点击“开始讲解 / Start”开启中文语音，之后自动翻页。可暂停、继续、前后翻页、选择目录、查看中文讲稿或全屏观看。浏览器需要首次点击才能播放有声内容。

## 内容范围

展示以项目中的 PeopleLedger-v2 为基础，使用虚构人员和合成交易。幻灯片所列功能、技术结构及 116 项测试结果对应演示制作时核验的本地应用版本。后续 Vercel 部署适配使用独立的云端配置与持久化存储，部署情况以实际发布结果为准。

Mandarin narration is embedded in both PowerPoint files. The 20 bilingual slides run for approximately 18 minutes 50 seconds with automatic transitions. Use desktop PowerPoint for the verified playback configuration. The browser version starts with a user click and supports navigation, pause/resume, full screen and the Chinese transcript.
